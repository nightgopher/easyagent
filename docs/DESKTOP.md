# Go 原生桌面客户端

EasyAgent 的唯一维护中桌面客户端是 `desktop-native/`，使用 Go / MyGo 原生界面，Bundle ID 为 `com.hwj.easyagent`。界面不使用 Electron、React、HTML 或 WebView；macOS 电脑控制通过随包提供的 Swift 系统助手实现。核心服务、TUI 和桌面应用均由 Go 构建；服务内嵌 Web 界面继续独立维护。

## 安装与启动

Apple Silicon Mac 从 Release 下载 `easyagent-native-darwin-arm64.dmg`，正式安装入口为 `/Applications/EasyAgent.app`。v0.17.1 及此前的公开包使用 ad hoc 签名；从 v0.17.2 起正式构建固定证书身份以保留系统授权，尚未进行 Developer ID 签名与 Apple 公证。由于自签证书没有团队 ID，主程序通过 `desktop-native/resources/easyagent.entitlements` 关闭 hardened runtime 库验证，否则较新的 macOS 会拒绝加载随包的终端渲染等嵌入库。原生客户端已接入签名更新：设置中可检查更新，并选择自动检查或后台下载。存在活动任务、待审批操作或未保存文件时会阻止退出与更新重启。更新频道需要正式 Release 发布签名清单及归档后才可用；发布构建要求见 RELEASING.md。

本机构建：

```sh
make desktop
open desktop-native/build.noindex/darwin-arm64/EasyAgent.app
```

构建脚本会验证实际 bundle 的核心查找、启动、`/health` 响应和退出回收。产物保存在 `.noindex` 目录，不自动替换现有应用或运行服务。原生 GUI 验收结束后先退出应用，再执行：

```sh
python3 scripts/unregister-desktop-apps.py desktop-native/build.noindex/darwin-arm64/EasyAgent.app
```

## 安装命令行

「设置 → 通用 → 命令行」可把应用内嵌的核心 CLI 安装为终端命令：应用创建 symlink `~/.easyagent/bin/easyagent` 指向包内 `Contents/Resources/easyagent`，目录与 `scripts/install.sh` 保持一致。应用自更新后 symlink 指向的内容自动跟进新版，无需重复安装。

若 `~/.easyagent/bin` 不在 PATH，安装时按当前 shell 追加一行带 `# EasyAgent` 注释的 PATH 配置（zsh → `~/.zshrc`，bash → `~/.bashrc`，fish 使用 `set -gx` 语法，其余 → `~/.profile`；已有 `.easyagent/bin` 配置时不重复写入），重启终端后生效；安装同时会创建空的 `~/.easyagent/.env` 作为命令行 env 配置入口。

「卸载命令行」仅删除该 symlink；`scripts/install.sh` 的独立安装或手动放置的同名命令不会被改动或覆盖。命令行与桌面端的模型配置、EasyCode 登录各自独立——桌面核心使用应用私有的 `EA_HOME=core-home`，命令行使用 `~/.easyagent`；需要命令行使用同一模型配置时按[配置说明](CONFIG.md)单独配置。

## 配置和数据

“运行主机”支持此 Mac 与远程 Go 服务。此 Mac 启动独立 loopback 核心，使用应用自己的 `core-data` 和 `core-home`；模型配置可沿用 CLI 默认值，也可在“模型连接”中单独设置。远程主机配置需要服务地址和 API 令牌。密钥由 macOS 钥匙串保存，普通 JSON 仅存元数据。

设置 →「手机远程访问」可开启加密中继并生成一次性配对二维码，Android / iOS 扫码连接这台电脑。中继首次注册需要独立接入码，设备可单独撤销；详见[远程访问](RELAY_ACCESS_DESIGN.md)。原有 Tailscale / 局域网主机保持原连接方式。

远程连接保存成功前会回读钥匙串验证令牌。原地址留空保留已存令牌；修改地址需重新填写令牌，新连接留空表示无令牌。相同地址与令牌重复保存保留连接 ID，普通编辑中实际更换地址或凭据会另存连接并保留原连接与草稿。移除连接会清空当前凭据并清理可访问的旧条目；受旧系统授权保护的条目可能保留，但不会再被自动使用。不删除远程会话或文件。

遇到 HTTP 401，点击错误提示中的“重新填写访问令牌”，会打开对应主机并聚焦令牌框；若其他设置表单未保存，会先确认是否放弃修改。401 后停止自动重试，保存正确凭据后重新连接；普通网络断线继续自动恢复。声明有令牌但凭据缺失的连接会直接提示修复，不发送无认证请求。

从 v0.32.0 起，通过上述入口修复令牌且服务地址保持不变时，保存到原连接 ID，保留其会话和草稿关联，不再留下一个失效旧入口与一个新入口。修复过程中更换服务地址仍创建独立身份。保存或回读失败会报告错误；原令牌可读取时尝试恢复原值，配置持久化成功后才应用连接。

macOS 的默认钥匙串与全局搜索列表可能不一致。凭据的读写均显式定位同一个默认钥匙串。v0.23.1 起由固定签名的专用凭据程序访问钥匙串，应用更新复用经过签名校验的程序；凭据程序自身更新时，通过原程序自动迁移到新程序的独立条目。父进程与子进程互相验证签名，密钥仅通过匿名管道传递，不写入普通配置或命令行参数。

更换签名证书（例如从自签证书升级到 Developer ID）后，旧签名的缓存凭据程序会保留但不再执行，也不会阻止当前程序保存新凭据。旧签名拥有的令牌或 API 密钥需要重新填写一次；客户端不会跨签名读取或回退到过期值。当前随包程序及其缓存仍须通过完整身份与权限校验。

可读取的旧 `com.hwj.easyagent.native-preview` 凭据会自动迁移。旧授权已失效时，客户端直接提供重新填写主机访问令牌或模型 API 密钥的入口，不反复弹出系统密码框。这里填写的是该服务的令牌或 API 密钥；旧弹窗要求的 “login” 钥匙串密码可能与当前 Mac 登录密码不同，客户端不会重置或更改它。

发布验证在独立的现代格式钥匙串中检查两个不同应用构建、凭据程序升级、拒绝其他签名/应用、清除后的重启、锁定失败和真实 REST / WebSocket 认证；使用虚构凭据，结束后删除测试钥匙串。

连接现有服务才能查看该服务上的会话。切换主机不会取消远程任务；退出应用会关闭它托管的本地核心。存在运行任务时，修改本地模型配置会拒绝重启，须先停止任务。

会话、工具审批、队列、文件工作台、终端、技能市场、MCP、飞书及音频能力见 [原生客户端说明](../desktop-native/README.md)。电脑控制需要 macOS 14+，辅助功能和屏幕录制授权仍由用户完成，见 [配置说明](CONFIG.md#实验性电脑控制)。

## 配色与背景壁纸

在「设置 → 外观」中独立选择配色与壁纸。默认仍为纯色，可选择内置「山间薄雾」「暮色海面」，或导入 PNG、JPEG、WebP；图片上限为 20 MB、2400 万像素。导入时复制到本机应用数据目录的 `wallpapers/`，不上传到所连接的主机，移动原图或切换主机不影响显示。

背景强度和模糊立即预览并保存在此设备；强度是相对于可读范围的调节，最大值仍保留主题遮罩。模糊仅作用于图片，侧栏、输入框与代码区域保留实色底。选择「纯色」暂时关闭壁纸但保留已导入图片；「移除图片」删除应用副本；「恢复默认」重置配色与背景，原始图片始终保留。图片损坏或无法读取时回到纯色底，并在外观页提供重新选择入口。

## 历史会话全文搜索

侧边栏的“搜索会话内容”会查找当前运行主机保存的标题、提问和回答，包括尚未打开的会话；默认包含归档。支持按项目、归档状态及最近 7 / 30 天筛选。`⌘⇧F`（Windows/Linux 为 `Ctrl+Shift+F`）打开侧边栏并聚焦搜索，`⌘F` / `Ctrl+F` 仍用于当前对话内查找。

结果显示命中文字、项目、时间与归档标记，每页 30 条。点击正文结果会跳到对应原始消息；该消息已被压缩或不在当前历史分支时，展示带前后文的只读历史片段，点击“返回当前对话”即可继续。查看历史不改变模型上下文，也不丢失草稿。

输入停止 250 毫秒后搜索，Enter 可立即搜索。索引保存在会话所属主机，重启客户端后仍可检索；首次建立索引可能需要等待。切换主机会清除旧结果，当前版本不会同时汇总多台主机。离线、旧版主机不支持、部分会话读取失败会分别提示，不会伪装成“没有结果”。这是关键词检索，暂不包含语义搜索和工具日志搜索。

## 持续任务跟进

在会话菜单选择「加入任务跟进」，再从侧栏「任务跟进」查看。只有明确加入的会话才会生成任务记录；普通聊天保持原样。任务归属当前主机和原 Agent，重启客户端后仍可查看。

「待处理」优先显示真实的工具审批、执行失败或中断，以及 Agent 登记的待回答问题、阻塞原因和待验收成果。「跟进中」包含全部未结束任务；「全部任务」还可查找历史交付。支持按任务名称、进展和成果检索，展开可查看完整说明并复制成果位置。列表只在打开时每 5 秒刷新，切换主机会取消旧请求。

「回到会话」直接返回原 Agent，不经过其他 Agent 转述，也不丢失未发送草稿。可让原 Agent 使用 `work_get` / `work_report` 更新当前任务的进展、问题和文件或链接。一次运行结束不会自动完成任务；由用户「标记完成」或「结束跟进」，之后仍可「重新跟进」。多端同时修改发生冲突时会提示刷新，不覆盖较新的版本。此入口需要主机同时提供 `/work` API。

## 可选的个人管家

侧栏「管家」首次打开时，为当前主机创建一个持久化业务 Agent；再次打开优先回到它最近的未归档会话。可问“哪些事情等我处理”“上次报告在哪个会话”“我有哪些专属 Agent”。它查询真实任务状态、历史会话片段和 Agent 目录，回答中的链接可直接回到原对话，正文命中可定位到原始内容。

管家是独立入口，编程和其他专属 Agent 仍可直接对话。打开管家不会自动发消息、创建跟进任务或分配工作；未发送草稿保留在原会话。管家拥有自己的记忆，只有明确要求记住时才应保存；不会共享其他 Agent 的独立记忆空间。

在「设置 → 业务 Agent → 个人管家 → 工具与技能」可以分别关闭任务查询、全部会话检索（含归档）或 Agent 目录权限，也可以修改说明、关闭记忆或停用管家。重复打开不会恢复已撤销的权限。当前只查所连接主机，不跨设备聚合；归档会话仍属于搜索范围，私密会话不应通过归档来隔离。

## 旧客户端归档

Electron / React 的 `desktop/`（含共用前端的 Capacitor Android 外壳）已退役，不再构建、测试或发布。从 v0.16.0 起 Release 不再要求 Electron DMG；已发布版本与资产不变。

历史源码与文档可从 [archive/workflow](https://github.com/nightgopher/easyagent/tree/archive/workflow/desktop) 查看，退役前的精确快照为 [e4b4088](https://github.com/nightgopher/easyagent/tree/e4b4088/desktop)。Electron 的自动更新、固定证书重签名及 safeStorage 数据不适用于原生客户端；本次退役不会删除旧用户数据、签名钥匙串或覆盖已安装应用。
