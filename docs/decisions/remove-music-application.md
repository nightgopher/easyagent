# 下线音乐应用

2026-11-04 决定并实施。EasyAgent 不再内置音乐应用、`music_*` 工具、网易云与 B 站音源、音频代理和桌面播放器；完整代码保留在 `archive/music` 分支（main 快照 `90d7229b`）。

## 原因

- 音乐应用只是绑定了特定工具和提示词，运行循环与会话都复用公共 runtime，会话扩展基本没有实际状态，达不到 [Skills 与 Application](skills-vs-application.md) 的增加门槛。
- 自研部分约 5400 行（含测试），依赖匿名网易云接口和 B 站接口，不受项目控制，也拿不到红心和个人歌单。
- 网易云官方已提供 `ncm-cli` 与 [NetEase/skills](https://github.com/NetEase/skills)，覆盖登录、搜索、播放控制、歌单管理和基于红心的推荐。个性化推荐依赖的听歌行为数据也在网易云一侧，不值得在本地重建。

## 领域能力的选择顺序

默认使用外部能力，外部做不到时才自己实现：

| 方式 | 适用情况 |
|---|---|
| Skill | 只是方法和流程，现有工具够用 |
| CLI + Skill | 有官方 CLI，本机单人使用，可以接受启用 bash |
| MCP | 需要收窄权限，或要给飞书、业务 Agent 等没有 bash 的入口使用 |
| 自研工具 | 必须和宿主的会话、权限、界面或自有数据深度绑定 |

## 影响

- 失去 B 站音源、桌面内置播放器和本地听歌历史积累。`ncm-cli` 需要入驻网易云开放平台并登录，播放发生在运行它的机器上。
- `application=music` 的历史会话不改元数据，打开时使用占位应用：历史可查看，只有返回下线提示的同名工具，不会获得默认应用的文件和命令工具。新建和分叉到 `music` 均被拒绝。
- `SessionSetup` 不再把未注册的应用回退为默认应用，避免应用被移除后会话静默获得更高权限。
- `music_pref.json` 和画像中的音乐分类保留，不再由音乐播放更新。
